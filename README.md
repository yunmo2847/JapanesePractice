- **콘텐츠**: Week 1 (Day 1–7) — 패턴 9개, 인출 카드 60장, 이어 쓰기 18세트, 프리토킹 주제 9개, 대화문 6개, 생존 표현 33개
- **기능 (P0)**: F0 로마자→가나 입력 · F1 프리토킹 채팅 + 자동 리포트 · F2 인출 카드(타이핑/블록/속으로, Leitner 복습) · F3 이어 쓰기·답변 확장 공식 · F5 듣기→반응 대화문(자막 3단계, 받아쓰기, 퀴즈) · F6 TTS(속도, 화자별 피치, 무성 쉐도잉) · F7 패턴 · F8 생존 표현집 · F10 진도·성장 비교·내보내기/가져오기 · F11 홈 · F12 설정
- **추가된 것 (P1)**: 멀티턴 프리토킹 — 유이가 맞장구 + 후속 질문 2개, 되물으면 자기 이야기 (`src/lib/partner.ts`) · 가타카나 표/퀴즈/외래어 읽기·쓰기
- **아직 없는 것 (P1 이후)**: Week 2–3 콘텐츠, 금지어 챌린지, 선택형 음성 체크인, 단어장, PWA

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 단위 테스트 + 콘텐츠 검증 (후리가나 누락, 정답 채점, 블록 분할 등)
npm run e2e        # Playwright: Day 1 전체 진행 + 폰/탭 세로·가로/PC 레이아웃
npm run build      # dist/ (정적 파일, 서버 불필요)
```

## 콘텐츠 작성 규칙

일본어 문장은 `src/content/*.json`에 다음 마크업으로 써요.

- `漢字{かんじ}`: 바로 앞 한자에 읽기(후리가나)를 붙여요. 채점용 가나 읽기도 여기서 자동으로 만들어져요.
- `|`: 블록 조립 연습에서 나뉘는 단위예요. 예: `私{わたし}は|学生{がくせい}|です。`

`npm test`를 돌리면 읽기가 빠진 한자, 스스로 정답 처리되지 않는 카드, 깨진 참조를 찾아줘요.
