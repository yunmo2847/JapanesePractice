# 니혼고 21 — 3주 일본어 말하기·듣기 집중 훈련 웹서비스 기획서 (PRD)

> 버전 v1.0 · 2026-10-11 · 작성: 기획 인터뷰 기반
> 상태: 초안 확정, 개발 착수 가능

---

## 0. 한 줄 요약

**3주 뒤 일본 고등학교 진학 + 홈스테이를 앞둔 나를 위해, "하고 싶은 말이 입에서 바로 나오게" 만드는 개인용 말하기·듣기 훈련 웹앱.**
PC·태블릿·휴대폰 어디서든 하루 30~60분, 21일 커리큘럼을 따라가며 패턴 → 듣기 → 따라 말하기 → 녹음 비교를 반복한다.

---

## 1. 배경과 문제 정의

### 1.1 사용자 상황 (인터뷰로 확정된 사실)

| 항목 | 내용 |
|---|---|
| 사용자 | 나 1명 (곧 일본 고등학교 진학 예정인 학생) |
| D-day | 오늘(2026-10-11) 기준 **3주 뒤 출국** → 학습 가능 기간 약 21일 |
| 현재 실력 | 히라가나·가타카나는 읽을 수 있음. 문장은 거의 못 만듦 |
| 하루 학습 시간 | 30~60분 |
| 말하기 연습 방식 | TTS 원어민 음성 듣고 **따라 말하기(쉐도잉) + 내 목소리 녹음 비교**. 음성인식·AI 대화는 사용 안 함 |
| 꼭 필요한 장면 | ① 홈스테이/집 ② 친구 사귀기·놀기 ③ 학교 첫날·교실 |
| 가장 큰 두려움 | **"하고 싶은 말이 입에서 안 나올까 봐"** |

### 1.2 진짜 문제

"단어를 모른다"보다 **"알아도 바로 못 꺼낸다"** 가 핵심 문제다.
따라서 이 서비스의 모든 기능은 **"한국어 의도 → 일본어 문장 즉시 발화"** (인출, retrieval) 훈련에 최적화한다.
읽고 이해하는 학습(인식)은 보조 역할로만 둔다.

### 1.3 설계 원칙

1. **말하기 우선 (Output-first)**: 카드의 기본 방향은 `한국어 → 일본어로 말해보기`. 일본어를 보고 뜻 맞히기는 보조 모드.
2. **패턴 1개로 문장 10개**: 단어 암기보다 "문장 틀 + 단어 교체"로 생성력 확보.
3. **장면 중심**: 모든 콘텐츠는 홈스테이 / 친구 / 학교 / 생활필수 중 하나의 장면 태그를 가진다.
4. **매일 끝이 보이게**: 오늘 할 일 = 1개 화면, 예상 소요시간 표시. 3주 동안 "뭘 해야 하지?" 고민 0회.
5. **빨리 만들고 바로 쓴다**: 개발에 3주를 쓰면 의미 없다. **MVP는 2일 안에 Day 1을 학습할 수 있는 상태**로 배포.

## 2. 목표와 성공 기준 (BM 대신 "성공"의 정의)

이 프로젝트는 **수익화 목표가 없는 개인용 도구**다. 따라서 기능 우선순위의 기준은 "돈"이 아니라 아래 지표다.

### 2.1 성공 지표

| 지표 | 목표치 | 측정 방법 (앱 내) |
|---|---|---|
| 커리큘럼 완주율 | 21일 중 **18일 이상** 완료 | 일별 완료 체크 기록 |
| 즉시 발화 가능 문장 수 | 출국 전 **150문장 이상**을 "3초 안에 말함"으로 자기평가 | 말하기 카드의 자기평가 `바로 말함` 누적 |
| 핵심 패턴 습득 | 핵심 문장 패턴 **30개** 모두 "바로 말함" 1회 이상 | 패턴별 상태 |
| 자연 속도 듣기 | Week 3 듣기 대화문을 **1.0배속, 자막 없이** 70% 이상 이해(자기평가) | 듣기 퀴즈 정답률 |
| 최종 리허설 | Day 21 "첫날 시뮬레이션"(자기소개 + 홈스테이 인사 + 친구에게 말 걸기) 녹음 완료 | 녹음 존재 여부 |

### 2.2 운영 모델 비교 (BM 섹션)

수익을 목표로 하지 않더라도, "누구에게 열 것인가"에 따라 만들어야 할 것이 달라지므로 3가지를 비교했다.

| 모델 | 내용 | 필요한 추가 개발 | 장점 | 단점 |
|---|---|---|---|---|
| **A. 개인 전용 (추천·채택)** | 나만 사용. 정적 사이트, 로그인 없음 | 없음 | 개발 최소 → 학습 시간 확보. 비용 0원 | 기기 간 진도 동기화가 기본 제공 안 됨 (→ 4.F7 내보내기/가져오기로 해결) |
| B. 무료 공개 | 같은 상황의 학생들에게 링크 공유 | 콘텐츠 정확도 검수 강화, 개인정보 고지 | 피드백 받을 수 있음 | 3주 안에 검수 부담 큼 |
| C. 추후 수익화 (프리미엄/광고) | 반응 좋으면 유료 콘텐츠·광고 | 계정, 결제, 서버 DB, 원어민 녹음 | 확장 가능성 | 지금 목표(3주 내 실력 향상)와 충돌. 개발이 학습 시간을 잡아먹음 |

**결론: A안 채택.** 결정 근거 — 성공 기준이 "출국 전 내 발화 능력"이므로, 계정·서버·결제에 쓰는 1시간은 곧 학습 1시간의 손실이다.
일본 도착 후 실제로 써보고 B/C로 확장할지 재판단한다. (그때 가격·전환 설계가 필요하면 Web-BM 스킬, 경쟁 서비스 조사가 필요하면 Web-DeepSearch 스킬로 진행)

## 3. 21일 커리큘럼 설계

### 3.1 전체 구조

| 주차 | 테마 | 목표 상태 | 장면 비중 |
|---|---|---|---|
| **Week 1 (Day 1–7)** | 뼈대 만들기 — 문장 구조 + 생존 표현 | 정중체(です・ます)로 자기소개, 질문, 부탁, 거절 가능 | 생활필수 40% · 홈스테이 30% · 학교 30% |
| **Week 2 (Day 8–14)** | 홈스테이 & 교실 실전 | 집에서의 하루, 교실 지시 알아듣기, 반말/존댓말 전환 | 홈스테이 40% · 학교 40% · 친구 20% |
| **Week 3 (Day 15–21)** | 친구 모드 — 반말·학생 말투·자연 속도 | 또래와 잡담, 축약형 알아듣기, 리액션 | 친구 60% · 학교 25% · 홈스테이 15% |

### 3.2 일자별 커리큘럼

| Day | 핵심 패턴 (말하기) | 장면 | 뉘앙스 노트 |
|---|---|---|---|
| 1 | `A は B です` / `A じゃないです` | 자기소개 기본 (이름·나이·국적) | です를 붙이면 처음 만난 사람에게 안전 |
| 2 | `〜を ください` / `〜は ありますか` | 편의점·식당 | すみません 3가지 용도 (사과·부르기·감사) |
| 3 | 동사 ます형 (行きます/食べます/します) + 조사 を・に・で | 하루 일과 말하기 | 조사 は vs が 첫 구분 (최소한만) |
| 4 | `〜たいです` / `〜が 好きです` | 취미·좋아하는 것 | 好き vs 大好き 강도 |
| 5 | `〜てください` / `〜てもいいですか` | 부탁·허락 | ちょっと… = 돌려 말하는 거절 |
| 6 | 질문사 (何・どこ・いつ・誰・どう) | 길 묻기·물건 찾기 | 聞き返し: もう一度お願いします / ゆっくりお願いします |
| 7 | **복습 + 리허설 ①** | 첫 만남 자기소개 30초 녹음 | — |
| 8 | 인사 세트 (いってきます/ただいま/いただきます/ごちそうさま) | 홈스테이 하루 | 일본 가정의 정형 인사가 왜 중요한지 |
| 9 | `〜ました` / `〜ませんでした` (과거) | 오늘 하루 보고하기 (저녁 식탁) | 「どうだった?」에 대답하는 법 |
| 10 | `〜ています` (진행/상태) | 교실 상황 (지금 뭐 해?) | 教室 지시어: 起立・礼・着席, 出席を取ります |
| 11 | **반말 전환**: です/ます ↔ 보통형 | 선생님 vs 친구 말투 비교 | 누구에게 반말? (先輩/後輩, 〜さん/〜くん/〜ちゃん/이름만) |
| 12 | `〜から` (이유) / `〜けど` (역접·완충) | 사정 설명, 부드럽게 말하기 | けど로 끝내는 일본식 완곡함 |
| 13 | `〜てもいい?` `〜しようか?` (제안) | 호스트 가족 도와주기, 방 규칙 | 「大丈夫です」가 거절일 때 |
| 14 | **복습 + 리허설 ②** | 홈스테이 저녁 대화 1분 녹음 | — |
| 15 | 반말 질문·리액션 (え、マジ? / そうなんだ / それな) | 친구와 첫 대화 | 맞장구(相槌)가 대화의 절반 |
| 16 | `〜しよう` (권유) / `〜行かない?` | 같이 놀자, 점심 같이 먹자 | 「行かない?」는 부정이 아니라 권유 |
| 17 | 축약형 듣기: 〜ちゃう/〜じゃん/〜てる/〜なきゃ/〜って | 자연 속도 잡담 듣기 | 글로 쓴 말 vs 실제 말소리 |
| 18 | 학생 어휘: 部活・放課後・テスト・LINE交換 | 동아리, 방과 후, 연락처 교환 | 「LINE交換しよう」 타이밍 |
| 19 | 감정·평가 표현 (やばい/すごい/うける/めっちゃ/微妙) | SNS·게임·유튜브 잡담 | やばい의 긍정/부정 양쪽 의미 |
| 20 | 곤란할 때 표현 (分からない / 日本語まだ下手で… / 何て言うの?) | 말이 막혔을 때 살아남기 | 모를 때 솔직히 말하는 게 호감 |
| 21 | **최종 리허설** | 첫날 시뮬레이션 3종 녹음 | — |

> 각 Day는 **새 패턴 1~2개 + 예문 10~15개 + 단어 15~25개 + 대화문 1개 + 뉘앙스 노트 1~2개**로 구성.

### 3.3 하루 학습 흐름 (30~60분)

| 순서 | 단계 | 시간 | 내용 |
|---|---|---|---|
| 1 | 워밍업 복습 | 5–10분 | 어제까지 배운 말하기 카드 중 복습 예정 카드 (간격 반복) |
| 2 | 오늘의 패턴 | 5–10분 | 패턴 설명 + 예문 듣기 → 단어 바꿔 끼우기 |
| 3 | 듣기 | 5–10분 | 장면 대화문 0.7배 → 1.0배 → 자막 숨기고 1.0배 + 이해 퀴즈 2~3문항 |
| 4 | 말하기 드릴 | 10–20분 | 한국어 보고 일본어로 말하기 → 정답 듣기 → 쉐도잉 → 녹음 비교 |
| 5 | 마무리 | 2–5분 | 오늘의 뉘앙스 노트 + 자기평가 + 완료 체크 |

30분 모드는 1·2·4·5단계만(듣기는 대화문 1회만), 60분 모드는 전 단계 + 추가 드릴 라운드.

## 4. 기능 명세 (Feature Spec)

우선순위: **P0** = MVP(출시 2일 내), **P1** = 1주차 중 추가, **P2** = 여유 있으면.

### F1. 홈 / 오늘의 학습 대시보드 — P0

오늘 해야 할 것 하나만 크게 보여주는 첫 화면.

- [ ] 접속 시 첫 화면에 `Day N / 21`, 오늘의 테마, 예상 소요시간(30분/60분 모드)이 보인다
- [ ] "오늘 학습 시작" 버튼 1개로 3.3의 흐름이 순서대로 시작된다 (탭 1번)
- [ ] 진행 중이던 단계가 있으면 "이어하기"로 해당 단계부터 재개된다
- [ ] 21일 진도 바(완료=채움, 오늘=강조, 미래=비활성)가 표시된다
- [ ] D-day 카운트다운("출국까지 N일")이 표시된다. 출국일은 설정에서 입력
- [ ] 오늘 Day는 "시작일 + 경과일"로 자동 계산하되, 수동으로 다른 Day 선택 가능 (밀렸을 때 따라잡기)

### F2. 말하기 카드 드릴 (핵심 기능) — P0

"한국어 의도 → 일본어 즉시 발화" 훈련.

- [ ] 카드 앞면: 한국어 의도 문장 + 장면 태그 + (선택) 힌트 단어. 예: `🏠 홈스테이 | "다녀왔습니다"`
- [ ] 사용자가 소리 내어 말한 뒤 "정답 보기"를 누르면 뒷면 공개: 일본어(한자+후리가나), 가나 표기, 한국어 뜻, 뉘앙스 한 줄
- [ ] 뒷면 공개와 동시에 TTS가 자동 재생된다 (설정에서 끌 수 있음)
- [ ] 3초 타이머: 앞면 표시 후 3초 경과 시 타이머 색이 바뀐다 → "3초 안에 말함" 기준을 시각화
- [ ] 자기평가 3단계 버튼: `바로 말함` / `떠올리긴 함` / `못 함`
- [ ] 자기평가 결과로 간격 반복(Leitner 5단계: 당일 → 1일 → 2일 → 4일 → 8일) 일정이 갱신된다
- [ ] `못 함` 카드는 같은 세션 끝에 한 번 더 나온다
- [ ] 모드 전환: 기본 `한→일 말하기`, 보조 `일→한 이해`
- [ ] 키보드 단축키(PC): `Space` 정답 보기, `1/2/3` 자기평가, `R` 다시 듣기

### F3. TTS 듣기 & 쉐도잉 플레이어 — P0

- [ ] 브라우저 내장 Web Speech API(`speechSynthesis`)의 `ja-JP` 음성으로 모든 일본어 문장을 재생한다
- [ ] 속도 선택: 0.7× / 0.85× / 1.0× / 1.2× (기본 0.85×, Week 3부터 기본 1.0×)
- [ ] 반복 재생: 같은 문장 N회(1/3/5) 자동 반복 + 문장 사이 간격(1~3초) 설정 → 쉐도잉용
- [ ] 기기에 `ja-JP` 음성이 없으면 안내 배너 표시 (iOS: 설정 > 손쉬운 사용 > 음성 콘텐츠에서 일본어 음성 다운로드 방법)
- [ ] 재생 중인 문장은 화면에서 하이라이트된다
- [ ] 대화문 재생 시 화자별로 다른 음성/피치를 사용한다 (기기에 음성이 1개뿐이면 피치만 다르게)

### F4. 녹음 & 비교 — P0

말한 것을 스스로 들어보는 기능 (음성인식은 사용하지 않음).

- [ ] 각 문장 카드에 🎙 녹음 버튼: 누르면 녹음 시작, 다시 누르면 정지 (`MediaRecorder` API)
- [ ] 녹음 후 `원어민(TTS) 듣기` ↔ `내 녹음 듣기`를 버튼 하나로 번갈아 재생할 수 있다
- [ ] 녹음은 기기 내(IndexedDB)에 저장되고, 문장당 최신 1개만 유지 (리허설 녹음은 Day별 보관)
- [ ] 마이크 권한 거부 시 녹음 버튼 대신 "권한 허용 방법" 안내 표시, 나머지 기능은 정상 동작
- [ ] 크롬(PC/안드로이드)과 사파리(iOS/iPadOS) 최신 버전에서 녹음·재생이 동작한다

### F5. 패턴 학습 화면 — P0

- [ ] 패턴 카드: 문장 틀(예: `〜てもいいですか`), 의미, 언제 쓰는지 1~2줄, 정중체/반말 버전 나란히 표시
- [ ] "단어 바꿔 끼우기" 드릴: 틀 고정 + 단어 칩 탭 → 완성 문장이 바뀌고 TTS 재생 (예: `トイレに行って` / `窓を開けて` / `写真を撮って` + `もいいですか`)
- [ ] 패턴마다 예문 최소 5개, 장면 태그 포함
- [ ] 관련 뉘앙스 노트로 바로 이동하는 링크

### F6. 듣기 대화문 — P0(Week 1분), P1(나머지)

- [ ] 대화문 단위: 장면 설명(한국어) + 4~10턴 대화 + 화자 표시
- [ ] 자막 3단계 토글: `일본어+한국어` → `일본어만` → `자막 없음`
- [ ] 이해 확인 퀴즈 2~3문항(4지선다, 한국어 문항). 정답률 저장
- [ ] 턴 단위 탭 → 해당 턴만 재생, 길게 누르면 그 문장을 말하기 카드로 추가

### F7. 진도 저장 & 기기 간 이동 — P0

로그인 없이 PC·패드·폰을 넘나들기 위한 최소 장치.

- [ ] 모든 진도(완료 Day, 카드별 Leitner 단계, 퀴즈 결과, 설정)는 `localStorage`에 자동 저장
- [ ] 설정 > "진도 내보내기": JSON 파일 다운로드 **및** 복사 가능한 짧은 텍스트 코드 생성
- [ ] 설정 > "진도 가져오기": 파일 업로드 또는 코드 붙여넣기로 복원. 덮어쓰기 전 확인창 표시
- [ ] 녹음 파일은 내보내기 대상에서 제외 (용량 문제) — 화면에 명시
- [ ] 저장 데이터에 버전 필드를 넣어 콘텐츠 업데이트 후에도 기존 진도가 깨지지 않는다

### F8. 뉘앙스 노트 & 학생 표현 사전 — P1

- [ ] 뉘앙스 노트 목록: 제목, 장면 태그, "이렇게 말하면 이렇게 들린다" 비교표
  - 예: `すみません / ごめん / ごめんなさい / 申し訳ありません` 상대·상황별 차이
  - 예: `いいです` 가 "좋아요"도 "괜찮아요(거절)"도 되는 경우
  - 예: 호칭 `〜さん / 〜くん / 〜ちゃん / 이름만 / 先輩`
- [ ] 학생 표현 사전: 표현, 의미, 쓰는 상대(친구만/선생님 X), 예문, 사용 주의도(🟢 아무 데나 / 🟡 친구끼리만 / 🔴 알아듣기만)
  - 예: `マジ` `やばい` `それな` `うける` `めっちゃ` `〜じゃん` `ガチ` `草`(SNS) `部活` `放課後` `先輩` `LINE交換しよう`
- [ ] 검색(일본어·가나·한국어 모두)과 장면 필터

### F9. 단어장 — P1

- [ ] Day별 단어 목록: 단어, 읽기, 뜻, 예문 1개, TTS
- [ ] 단어 탭 → 해당 단어가 들어간 예문 전부 보기
- [ ] "모름" 표시한 단어만 모아보기

### F10. 리허설 모드 (Day 7 / 14 / 21) — P1

- [ ] 상황 프롬프트(한국어)만 보고 30초~1분 자유롭게 말하며 녹음
- [ ] 녹음 후 "모범 답안" 스크립트 + TTS 공개
- [ ] Day 7·14·21 녹음을 나란히 재생 → 성장 비교

### F11. PWA 오프라인 지원 — P2

- [ ] 홈 화면에 추가 가능 (manifest, 아이콘)
- [ ] 한 번 접속 후 비행기 모드에서도 학습 가능 (Service Worker로 콘텐츠·앱 캐시)
- 일본 도착 직후 데이터가 불안정할 때 복습용으로 유용

### F12. 설정 — P0

- [ ] 출국일, 학습 시작일, 하루 모드(30/60분), 기본 TTS 속도, 후리가나 표시 on/off, 자동 재생 on/off
- [ ] 다크 모드 (시스템 설정 따름 + 수동 전환)

## 5. 콘텐츠 명세

### 5.1 분량 목표 (21일 합계)

| 콘텐츠 | 분량 | 비고 |
|---|---|---|
| 핵심 문장 패턴 | 30개 | 정중체/반말 쌍으로 |
| 말하기 카드(예문) | 300개 내외 | Day당 10~15개 + 복습 |
| 단어 | 400개 내외 | 고빈도 일상어 + 학교/홈스테이 어휘 |
| 듣기 대화문 | 21개 | Day당 1개, 4~10턴 |
| 뉘앙스 노트 | 25개 | |
| 학생 표현 | 60개 | 주의도 태그 필수 |

### 5.2 데이터 구조 (JSON, 정적 파일)

```jsonc
// content/sentences.json 의 한 항목
{
  "id": "s-d08-003",
  "day": 8,
  "scene": "homestay",           // homestay | friends | school | survival
  "ko": "다녀왔습니다",
  "ja": "ただいま",
  "kana": "ただいま",
  "furigana": null,               // 한자가 있을 때 [{ "text": "行", "ruby": "い" }, ...]
  "register": "casual",          // polite | casual | both
  "nuance": "집에 돌아왔을 때 항상 하는 고정 인사. 가족은 「おかえり」로 답한다.",
  "patternId": null,
  "tags": ["greeting"]
}
```

`patterns.json`, `vocab.json`, `dialogues.json`, `nuances.json`, `slang.json`, `curriculum.json`(Day → 콘텐츠 id 목록)도 같은 원칙(장면·Day·레지스터 태그 필수)으로 구성.

### 5.3 콘텐츠 정확도 원칙

- 모든 일본어 문장은 **자연스러운 실제 회화체**를 기준으로 작성 (교과서체만 고집하지 않음)
- 학생 표현은 반드시 **주의도 태그**(🟢/🟡/🔴)를 단다 — 선생님·호스트 가족 앞에서 실수 방지
- 콘텐츠는 AI가 초안 작성 → **Week별로 사용 전 1회 검수** (가능하면 일본어 잘하는 지인/선생님에게 Week 3 학생 표현 위주로 확인 요청)
- 오류 발견 시 카드에서 바로 "🚩 이상함" 표시 → 설정에서 신고 목록 확인 후 수정

## 6. 화면 구성 & 반응형 기준

### 6.1 화면 목록

1. 홈(오늘의 학습) 2. 학습 세션(단계별 진행) 3. 말하기 카드 4. 패턴 5. 듣기 대화문 6. 뉘앙스·학생 표현 7. 단어장 8. 진도(21일 캘린더 + 지표) 9. 설정

### 6.2 반응형 기준

| 기기 | 기준 폭 | 레이아웃 |
|---|---|---|
| 휴대폰 | 360–767px | 하단 탭바(홈/학습/사전/진도/설정), 카드 1장 전체 폭, 버튼은 엄지 영역(화면 하단 1/3) |
| 태블릿 | 768–1023px | 하단 탭바 유지, 카드 + 보조 패널(뉘앙스/단어) 2단 가능, 가로·세로 모두 지원 |
| PC | 1024px 이상 | 좌측 사이드바 네비게이션, 콘텐츠 최대 폭 960px 중앙 정렬, 키보드 단축키 |

### 6.3 측정 가능한 UX 기준

- [ ] 어떤 화면에서든 "오늘 학습 시작/이어하기"까지 **탭 2번 이내**
- [ ] 모든 터치 대상 최소 **44×44px**
- [ ] 일본어 본문 글자 크기 모바일 **20px 이상**, 후리가나는 본문의 50%
- [ ] 360px 폭에서 **가로 스크롤 없음**
- [ ] 첫 화면 로딩 3G 기준 **3초 이내** (콘텐츠 JSON은 Day 단위로 분할 로드)
- [ ] 카드 정답 보기 → TTS 재생 시작까지 **0.5초 이내**

## 7. 기술 스택 & 아키텍처

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Vite + React + TypeScript | 빠른 개발, 컴포넌트 재사용, 정적 빌드 |
| 스타일 | CSS Modules 또는 Tailwind | 반응형 브레이크포인트 관리 용이 |
| 음성 출력 | Web Speech API `speechSynthesis` (ja-JP) | 무료, 설치 불필요, iOS/안드로이드/PC 지원 |
| 녹음 | `MediaRecorder` + IndexedDB | 무료, 서버 불필요 |
| 데이터 | 정적 JSON (`/content`) | 서버·DB 불필요, Git으로 버전 관리 |
| 진도 저장 | `localStorage` + 내보내기/가져오기 | 로그인 없이 기기 간 이동 |
| 배포 | GitHub Pages (또는 Vercel/Netlify 무료) | 비용 0원, push 시 자동 배포 |
| 오프라인 | (P2) `vite-plugin-pwa` | |

**서버 없음 · 로그인 없음 · 비용 0원.**

### 기술 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| 기기마다 TTS 일본어 음성 품질·유무가 다름 | 듣기 품질 저하 | 음성 선택 드롭다운 제공, 없을 때 설치 안내. P2로 미리 생성한 mp3(무료 TTS로 빌드 시 생성) 검토 |
| iOS Safari의 `MediaRecorder`/자동재생 제약 | 녹음·자동재생 실패 | 사용자 탭 이벤트 안에서만 재생 시작, 실기기(아이폰/아이패드) 테스트를 P0 완료 조건에 포함 |
| `localStorage`는 기기별로 분리 | 진도 불일치 | F7 내보내기/가져오기. 주 기기 1대를 "메인"으로 정해 사용 권장 |
| AI 작성 콘텐츠의 부자연스러운 표현 | 잘못된 표현 습득 | 5.3 검수 원칙, 🚩 신고 기능 |
