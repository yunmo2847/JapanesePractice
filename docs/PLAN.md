# 니혼고 21 — 일본어 프리토킹 훈련 웹서비스 기획서 (PRD)

> 버전 v2.0 · 2026-10-11
> 변경: v1(일본 고등학교·홈스테이 상황 맞춤) → **v2(프리토킹 실력 향상 단일 목표)**

---

## 0. 한 줄 요약

**어떤 주제가 나와도 일본어로 끊기지 않고 1~2분 이상 이어 말하는 힘을 기르는 21일 프리토킹 훈련 웹앱.**
PC·태블릿·휴대폰 어디서든 하루 30~60분. 매일 "문장 조립 → 이어 말하기 → 주제 프리토킹 녹음"을 반복한다.

---

## 1. 목표 정의

### 1.1 단일 목표

> **프리토킹 실력 향상** — 준비되지 않은 주제에 대해, 일본어로, 멈추지 않고, 상대와 주고받으며 말할 수 있다.

특정 장소·상황(학교, 홈스테이, 여행 등)에 맞춘 표현 암기는 이 서비스의 목표가 **아니다.**
모든 콘텐츠와 기능은 "이것이 프리토킹을 더 길게, 덜 막히게, 더 자연스럽게 만드는가?"로만 판단한다.

### 1.2 프리토킹을 구성하는 5가지 능력

프리토킹이 안 되는 이유를 쪼개면 다섯 가지이고, 각 기능은 이 중 하나 이상을 훈련한다.

| # | 능력 | 막히는 모습 | 훈련 방법 |
|---|---|---|---|
| ① | **즉시 인출** | 아는 말인데 바로 안 나옴 | 한→일 3초 말하기 카드 |
| ② | **문장 잇기** | 한 문장 말하고 끝남 | 접속 표현(〜て、〜から、〜けど、それで、だから) 드릴, 이어 말하기 |
| ③ | **답 늘리기** | 「はい、好きです。」로 대화 종료 | 답변 확장 공식 (답 → 이유 → 예시 → 되묻기) |
| ④ | **막혔을 때 버티기** | 단어 모르면 침묵 | 바꿔 말하기(言い換え), 시간 버는 말(えっと、なんか、何て言うんだろう), 되묻기 |
| ⑤ | **주고받기** | 질문에 답만 함 | 맞장구(相槌), 되묻기(〜は?), 리액션, 화제 전환 |

### 1.3 사용자 조건 (인터뷰로 확정)

| 항목 | 내용 |
|---|---|
| 사용자 | 나 1명 |
| 시작 실력 | 히라가나·가타카나는 읽음, 문장은 거의 못 만듦 |
| 기간 | 21일 프로그램 (끝난 뒤에도 프리토킹 주제 반복 사용) |
| 하루 학습 시간 | 30~60분 |
| 말하기 연습 방식 | TTS 원어민 음성 듣고 따라 말하기 + 내 목소리 녹음 비교. 음성인식·AI 대화 미사용 |

### 1.4 설계 원칙

1. **매일 반드시 "자유롭게 말하기"로 끝난다.** 입력(듣기·패턴)은 출력(프리토킹)을 위한 재료일 뿐이다.
2. **암기보다 조립.** 통문장 대신 "틀 + 교체 단어 + 접속 표현"으로 처음 보는 말도 만들 수 있게.
3. **길이를 점진적으로 늘린다.** 1문장 → 3문장 → 30초 → 1분 → 2분.
4. **완벽함보다 계속 말하기.** 틀려도 멈추지 않는 것을 평가 기준으로 삼는다.
5. **빨리 만들고 바로 쓴다.** MVP는 2일 안에 Day 1을 할 수 있는 상태로 배포.

## 2. 성공 기준 & 운영 모델

### 2.1 성공 지표

| 지표 | 목표치 | 측정 방법 (앱 내) |
|---|---|---|
| 연속 발화 시간 | Day 21에 처음 보는 주제로 **2분** 멈춤 없이 말하기 녹음 | 프리토킹 녹음 길이 + 자기평가 "3초 이상 멈춤 횟수" |
| 즉시 인출 문장 수 | **150문장 이상** "3초 안에 말함" | 말하기 카드 자기평가 누적 |
| 접속 표현 사용 | 프리토킹 1회당 접속 표현 **5개 이상** 사용 | 프리토킹 후 체크리스트 자기평가 |
| 주제 커버리지 | 프리토킹 주제 **30개** 중 25개 이상 1회 이상 녹음 | 주제별 완료 기록 |
| 완주율 | 21일 중 **18일 이상** 완료 | 일별 완료 기록 |

### 2.2 운영 모델 비교

| 모델 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 개인 전용 (채택)** | 정적 사이트, 로그인 없음 | 개발 최소, 비용 0원, 학습 시간 확보 | 기기 간 진도는 내보내기/가져오기로 수동 이동 |
| B. 무료 공개 | 링크로 다른 학습자와 공유 | 피드백 가능 | 콘텐츠 검수 부담 |
| C. 추후 수익화 | 프리미엄 주제팩, AI 피드백 유료화 | 확장성 | 계정·결제·서버 필요, 지금 목표와 충돌 |

**결론: A안.** 성공 기준이 "내 프리토킹 실력"이므로 계정·서버·결제는 학습 시간만 뺏는다. 21일 후 써본 결과로 B/C를 재검토한다. (그때 필요하면 Web-BM / Web-DeepSearch 스킬 활용)

## 3. 21일 커리큘럼

### 3.1 전체 구조

| 주차 | 테마 | 주차 종료 시 할 수 있는 것 | 프리토킹 길이 목표 |
|---|---|---|---|
| **Week 1 (Day 1–7)** | 문장 뼈대 — 말할 재료 만들기 | 나·좋아하는 것·일상에 대해 정중체로 3~5문장 연속 발화 | 30초 |
| **Week 2 (Day 8–14)** | 이어 말하기 — 문장을 길게 | 과거 경험 이야기, 이유·의견 붙이기, 막혔을 때 바꿔 말하기 | 1분 |
| **Week 3 (Day 15–21)** | 주고받기 — 대화를 굴리기 | 반말 대화, 맞장구·되묻기·화제 전환, 자연 속도 듣고 반응 | 2분 |

### 3.2 일자별 커리큘럼

| Day | 문장 재료 (패턴) | 프리토킹 스킬 | 오늘의 프리토킹 주제 |
|---|---|---|---|
| 1 | `A は B です` / `A じゃないです` | 자기소개 3문장 | 나에 대해 |
| 2 | 동사 ます형 + 조사 を・に・で | 시간 순서로 말하기 (朝… それから…) | 나의 하루 |
| 3 | `〜が好きです` / `〜が苦手です` | **답변 확장 공식** ① 답 → 이유(〜から) | 좋아하는 음식 |
| 4 | `〜たいです` / `〜つもりです` | 답변 확장 ② 예시 붙이기 (例えば…) | 해보고 싶은 것 |
| 5 | い/な형용사 + `〜です` / `〜かった` | 묘사하기 (どんな?) | 내 방 / 우리 동네 |
| 6 | 질문사 (何・どこ・いつ・誰・どう・なんで) | **되묻기** (〇〇さんは?) | 취미 (질문 3개 섞기) |
| 7 | **복습 + 30초 프리토킹 테스트** | — | 랜덤 주제 3개 |
| 8 | `〜ました` / `〜ませんでした` | 과거 이야기 순서 잡기 (最初に → それで → 最後に) | 지난 주말 |
| 9 | `〜て、〜て` (동작 잇기) | **문장 잇기** ① て형 | 최근에 한 일 |
| 10 | `〜から` / `〜ので` | 이유 붙이기 습관화 | 좋아하는 계절과 이유 |
| 11 | `〜けど` / `でも` | 반대·완충 (好きだけど…) | 장단점 말하기 (스마트폰) |
| 12 | `〜と思います` / `〜かな` | **의견 말하기** | ○○ vs ○○ 어느 쪽? |
| 13 | `〜みたいな` / `〜っていうか` / `何て言うんだろう` | **막혔을 때 버티기** (바꿔 말하기, 시간 벌기) | 설명하기 어려운 것 (내가 좋아하는 게임/앱 설명) |
| 14 | **복습 + 1분 프리토킹 테스트** | — | 랜덤 주제 3개 |
| 15 | です/ます ↔ 보통형(반말) 전환 | 반말 프리토킹 | 앞의 주제를 반말로 다시 |
| 16 | 맞장구: `そうなんだ` `へえ` `なるほど` `それな` `マジで?` | **주고받기** ① 리액션 | 대화문 따라 리액션 연습 |
| 17 | `〜じゃん` `〜ちゃう` `〜てる` `〜なきゃ` `〜って` (축약형) | 자연 속도 듣기 → 바로 대답 | 친구와 근황 이야기 |
| 18 | `〜しない?` `〜しようよ` (권유) | 대화 이끌기, 제안 | 같이 하고 싶은 것 |
| 19 | 감정·평가 (やばい・すごい・ウケる・めっちゃ・微妙・最高) | 감정 실어 말하기 | 최근 본 영상/드라마/웹툰 |
| 20 | `そういえば` `話変わるけど` `ところで` | **화제 전환** | 주제 3개를 자연스럽게 이어 말하기 |
| 21 | **최종 2분 프리토킹 테스트** | — | 처음 보는 주제 3개 + Day 7·14와 비교 |

> 각 Day: 새 패턴 1~2개 · 예문 10~15개 · 단어 15~20개 · 듣기 대화문 1개 · 프리토킹 주제 1개(+예비 2개)

### 3.3 하루 학습 흐름 (30~60분)

| 순서 | 단계 | 시간 | 내용 | 훈련 능력 |
|---|---|---|---|---|
| 1 | 워밍업 복습 | 5–10분 | 복습 예정 말하기 카드 (간격 반복) | ① |
| 2 | 문장 재료 | 5–10분 | 오늘의 패턴 + 단어 바꿔 끼우기 | ①② |
| 3 | 듣기 → 반응 | 5–10분 | 대화문 듣기 후, 마지막 질문에 내가 대답하기 | ⑤ |
| 4 | 이어 말하기 드릴 | 5–10분 | 1문장 → 접속 표현으로 3문장까지 늘리기 | ②③ |
| 5 | **프리토킹 녹음** | 5–15분 | 주제 보고 준비 없이 말하기 → 모범 답안 듣기 → 다시 말하기 | 전부 |
| 6 | 마무리 | 2–5분 | 셀프 체크리스트 + 완료 | — |

30분 모드: 1·2·5·6단계 (프리토킹 1회). 60분 모드: 전 단계 + 프리토킹 2회차.

## 4. 기능 명세 (Feature Spec)

우선순위 **P0** = MVP(2일 내), **P1** = 1주차 중, **P2** = 여유 있으면.

### F1. 프리토킹 스튜디오 (핵심 기능) — P0

준비 없이 주제를 받아 정해진 시간 동안 말하고 녹음하는 화면.

- [ ] 주제 카드 표시: 한국어 질문 + 일본어 질문(TTS 재생) + 난이도. 예: `週末は何をしましたか? / 주말에 뭐 했어요?`
- [ ] "힌트 보기"(선택): 쓸 만한 패턴 3개·단어 5개·접속 표현. 기본은 숨김 — 먼저 힌트 없이 시도
- [ ] 목표 시간 선택: 30초 / 1분 / 2분 (주차별 기본값 자동). 원형 타이머 + 남은 시간 표시
- [ ] 녹음 버튼 1번으로 타이머와 녹음이 동시에 시작, 시간 종료 시 자동 정지 (중간에 수동 정지 가능)
- [ ] 녹음 후 **모범 답안** 공개: 같은 주제의 일본어 답변(3~8문장) + 한국어 해석 + TTS + 사용된 접속 표현 하이라이트
- [ ] "다시 말하기" 버튼: 모범 답안을 본 뒤 2회차 녹음. 1회차·2회차를 나란히 재생 가능
- [ ] **셀프 체크리스트** (녹음 후):
  - [ ] 3초 이상 멈춘 횟수 (0 / 1–2 / 3+)
  - [ ] 접속 표현을 몇 개 썼나 (0–1 / 2–4 / 5+)
  - [ ] 이유나 예시를 붙였나 (Y/N)
  - [ ] 마지막에 되묻기를 했나 (Y/N)
  - [ ] 모르는 말을 바꿔 말해서 넘어갔나 (Y/N)
- [ ] "말하고 싶었는데 못 한 말" 메모 칸(한국어) → 저장 시 개인 말하기 카드 후보 목록에 추가 (일본어는 나중에 직접/사전으로 채움)
- [ ] 주제 랜덤 뽑기 버튼: 이미 한 주제 중 랜덤, 또는 아직 안 한 주제 중 랜덤

### F2. 말하기 카드 (즉시 인출) — P0

- [ ] 앞면: 한국어 문장 + 능력 태그(①~⑤). 예: `[문장 잇기] "어제 친구를 만나서 영화를 봤어요"`
- [ ] 정답 보기 → 일본어(한자+후리가나), 가나, 뜻, 뉘앙스 한 줄 + TTS 자동 재생
- [ ] 앞면 표시 후 3초 경과 시 타이머 색 변경
- [ ] 자기평가 `바로 말함` / `떠올리긴 함` / `못 함` → Leitner 5단계(당일→1→2→4→8일) 갱신
- [ ] `못 함` 카드는 세션 끝에 재출제
- [ ] 단축키(PC): `Space` 정답, `1/2/3` 평가, `R` 다시 듣기, `M` 녹음

### F3. 이어 말하기 드릴 (문장 잇기·답 늘리기) — P0

- [ ] 시작 문장 1개가 주어진다. 예: `日曜日に友達に会いました。`
- [ ] 접속 표현 칩 중 하나를 고르면(`それで` / `〜から` / `でも` / `例えば`) 그 뒤를 이어 말하도록 유도 → 예시 이어 문장 공개
- [ ] 3단계까지 이어서 최종 3~4문장 완성본을 TTS로 듣고 전체 녹음
- [ ] **답변 확장 공식** 템플릿: `답 → 이유(〜から) → 예시(例えば) → 되묻기(〇〇は?)` 4칸을 순서대로 채워 말하는 모드
- [ ] Day마다 최소 3세트

### F4. TTS 듣기 & 쉐도잉 플레이어 — P0

- [ ] Web Speech API `speechSynthesis` `ja-JP` 음성으로 모든 일본어 재생
- [ ] 속도 0.7× / 0.85× / 1.0× / 1.2× (기본 0.85×, Week 3부터 1.0×)
- [ ] 같은 문장 1/3/5회 반복 + 간격 1~3초 설정 (쉐도잉)
- [ ] 일본어 음성이 없으면 설치 방법 안내 배너 (iOS·안드로이드·Windows·macOS)
- [ ] 재생 중 문장 하이라이트, 대화문은 화자별 다른 음성/피치

### F5. 녹음 & 비교 — P0

- [ ] 모든 문장·드릴·프리토킹에서 `MediaRecorder` 녹음, IndexedDB 저장
- [ ] `원어민(TTS)` ↔ `내 녹음` 번갈아 재생 버튼
- [ ] 문장 카드는 최신 1개 보관, 프리토킹은 주제별 전체 기록 보관 (날짜 표시)
- [ ] 마이크 권한 거부 시 안내 표시, 녹음 외 기능은 정상 동작
- [ ] 크롬(PC/안드로이드)·사파리(iOS/iPadOS) 실기기에서 동작 확인

### F6. 문장 재료(패턴) 화면 — P0

- [ ] 패턴 카드: 틀, 의미, 쓰임 1~2줄, 정중체/반말 나란히
- [ ] 단어 바꿔 끼우기: 단어 칩 탭 → 완성 문장 변경 + TTS
- [ ] 패턴별 예문 5개 이상, 그 패턴을 쓸 수 있는 프리토킹 주제 링크

### F7. 듣기 → 반응 대화문 — P0(Week 1분), P1(나머지)

- [ ] 대화문 4~10턴, 자막 3단계 토글 (`일+한` → `일본어만` → `없음`)
- [ ] **마지막 턴은 나에게 던지는 질문** → 들은 즉시 녹음으로 대답 (정답 없음, 모범 답안 참고용 공개)
- [ ] 이해 퀴즈 2~3문항(4지선다)
- [ ] 대화문 속 맞장구·되묻기 표현은 색으로 강조 (주고받기 패턴 학습)
- [ ] 턴 길게 누르기 → 말하기 카드로 추가

### F8. 프리토킹 생존 표현집 — P0

막혔을 때 꺼내 쓰는 표현 모음. 프리토킹 화면에서 언제든 열 수 있는 하단 시트.

- [ ] 카테고리: 시간 벌기 / 바꿔 말하기 / 되묻기·확인 / 맞장구 / 화제 전환 / 의견 / 감정
  - 시간 벌기: `えっと` `なんか` `そうですね…` `何て言うんだろう`
  - 바꿔 말하기: `〜みたいなもの` `〜っていう意味` `英語で言うと〜` `簡単に言うと`
  - 되묻기: `〇〇は?` `どう思う?` `もう一回言って?` `〜ってどういう意味?`
- [ ] 각 표현: 일본어, 뜻, 정중/반말 구분, 예문, TTS
- [ ] 즐겨찾기 → 프리토킹 화면 힌트에 우선 표시

### F9. 진도 & 기록 — P0

- [ ] `localStorage`에 진도·카드 단계·체크리스트·설정 자동 저장
- [ ] 진도 화면: 21일 캘린더, 성공 지표 5개 현황 (2.1 기준)
- [ ] **성장 비교**: Day 7·14·21 테스트 녹음과 같은 주제의 과거 녹음을 나란히 재생
- [ ] 진도 내보내기(JSON 파일 + 복사용 코드) / 가져오기(덮어쓰기 전 확인). 녹음은 제외됨을 명시
- [ ] 저장 데이터에 버전 필드 → 콘텐츠 업데이트 후에도 진도 유지

### F10. 홈(오늘의 학습) — P0

- [ ] 첫 화면: `Day N / 21`, 오늘의 프리토킹 주제, 예상 소요시간, "시작/이어하기" 버튼 1개
- [ ] 3.3 흐름을 순서대로 진행, 중단 지점에서 재개
- [ ] 밀린 날은 수동으로 Day 선택 가능
- [ ] 21일 완료 후에는 "프리토킹 자유 연습" 모드(랜덤 주제 + 복습 카드)가 홈이 된다

### F11. 설정 — P0

- [ ] 시작일, 30/60분 모드, 기본 TTS 속도, 음성 선택, 후리가나 on/off, 자동 재생 on/off, 다크 모드

### F12. 단어장 — P1

- [ ] Day별 단어, 읽기, 뜻, 예문, TTS / "모름" 단어만 보기

### F13. PWA 오프라인 — P2

- [ ] 홈 화면 추가, Service Worker로 오프라인 학습

### 5.4 콘텐츠 품질 원칙

- 실제 회화체 기준. 모범 답안은 "완벽한 문어"가 아니라 **실제로 사람이 말하는 길이와 구조**(짧은 문장 + 접속 표현)
- 모든 모범 답안은 **답 → 이유/예시 → 되묻기** 구조를 지켜 그 자체가 교본이 되게 함
- 반말·속어에는 사용 범위 태그 (🟢 어디서나 / 🟡 친한 사이만 / 🔴 알아듣기만)
- AI 초안 → 주차 시작 전 검수. 카드의 🚩 버튼으로 오류 표시

## 7. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Vite + React + TypeScript | 빠른 개발, 정적 빌드 |
| 스타일 | Tailwind 또는 CSS Modules | 반응형 관리 |
| 음성 출력 | Web Speech API `speechSynthesis` | 무료, 설치 불필요 |
| 녹음 | `MediaRecorder` + IndexedDB | 서버 불필요 |
| 데이터 | 정적 JSON | Git 버전 관리 |
| 진도 | `localStorage` + 내보내기/가져오기 | 로그인 없음 |
| 배포 | GitHub Pages / Vercel 무료 | 비용 0원 |
| 오프라인 | (P2) `vite-plugin-pwa` | |

### 기술 리스크

| 리스크 | 대응 |
|---|---|
| 기기별 TTS 일본어 음성 품질·유무 차이 | 음성 선택 드롭다운, 설치 안내. P2로 빌드 시 mp3 사전 생성 검토 |
| iOS Safari 녹음·자동재생 제약 | 사용자 탭 이벤트 안에서만 재생 시작, 실기기 테스트를 P0 완료 조건에 포함 |
| 긴 프리토킹 녹음 용량 (2분 × 다수) | 주제별 최근 5개만 보관 + 테스트(Day 7/14/21) 녹음은 영구 보관, 저장 용량 표시 |
| 기기별 `localStorage` 분리 | 내보내기/가져오기, 메인 기기 1대 권장 |
| 음성인식이 없어 객관적 피드백 부재 | 모범 답안 비교 + 셀프 체크리스트 + 성장 비교 녹음으로 대체 (범위 밖 항목 참조) |
